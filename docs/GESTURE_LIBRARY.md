# 🎭 Gesture Library (Actions TBD)

## Gestures We Have (No Actions Yet)

### BRUSH DIRT OFF SHOULDER
**Motion**: Hand brushes shoulder in dismissive motion
**Potential uses**: 
- Dismiss notification
- Clear alerts
- Mark as read
- "Not important"

### HANDS DOWN TORSO (Smoothing)
**Motion**: Both hands sweep down chest/torso
**Potential uses**:
- Refresh screen
- Reset view
- Clear filters
- "Start fresh"

### FISTS ROTATING (Old-School Dance)
**Motion**: Fists rotating around each other
**Potential uses**:
- Video/audio scrubbing (precise!)
- Timeline navigation
- Fine-tune adjustment
- Scroll through frames

### FINGER GUNS 👉👉
**Motion**: Double finger pistols
**Potential uses**:
- Quick select multiple items
- "You got it" confirmation
- Bookmark/pin items

### MIND BLOWN 🤯
**Motion**: Hands at temples, then explode outward
**Potential uses**:
- Expand to fullscreen
- Show all details
- "Show me everything"

### SHOO FLY
**Motion**: Waving hand like shooing fly
**Potential uses**:
- Dismiss popup
- Skip ad
- "Go away"

### PRAYER HANDS 🙏
**Motion**: Palms together at chest
**Potential uses**:
- Save progress
- "Please work"
- Merge/combine items

### HAND ON HEART
**Motion**: Right hand over heart
**Potential uses**:
- Add to favorites
- "I promise" (accept terms?)
- Personal/private mode

### TIMEOUT GESTURE
**Motion**: Both hands form "T"
**Potential uses**:
- Pause everything
- Break/intermission
- System timeout

### STEERING WHEEL
**Motion**: Hands at 10 and 2, rotating
**Potential uses**:
- Navigate 3D space
- Game control
- Rotate view

## Gesture Banking

Store these for when we need them! Better to have gestures waiting for actions than actions waiting for gestures.

## Design Philosophy

1. **Natural First** - Use gestures people already make
2. **Big & Clear** - No tiny movements
3. **Fun** - Should feel good to do
4. **Universal** - Cross-cultural when possible
5. **Reusable** - Same gesture, different contexts
